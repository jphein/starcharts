# Handoff: Starcharts

A celebratory gratitude/reward app where groups (families, couples, friends) give each other "stars" on a shared night-sky canvas. Each star is a hand-drawn, named gift — not a count. Charts have a goal and a real-world reward; completing a chart turns the sky into a permanent constellation memory.

## About the Design Files

The files in this bundle are **design references created in HTML** — high-fidelity prototypes showing the intended look, feel, and interaction model. They are NOT production code to ship.

The task is to **recreate these designs in the target codebase** using its existing patterns (React Native, SwiftUI, Flutter, web React, etc.). If no environment exists yet, choose the framework best suited for a multi-platform consumer app with rich canvas rendering — likely React Native with `react-native-skia` for the sky/star rendering, or native iOS/Android with custom canvas layers.

## Fidelity

**High-fidelity.** Exact colors, typography, spacing, animation timings, and micro-interactions are committed to. Recreate pixel-perfectly using the codebase's existing primitives. Star SVGs in the prototype are placeholder geometry — final stars will be **transparent PNGs generated by an image model** (presets) and a **diffusion model** (custom-summoned stars). The recipient should accept any transparent PNG and render it with additive glow + parallax drift.

## Core Concept

- A **chart** is a shared goal (e.g. "Summer of Kindness — 50 stars → family camping trip"). Multiple members contribute.
- A **gift** = giving a star to another member with a reason ("for reading to your brother before bed"). Each gift can be 1, 2, 3, or 5 stars worth ("brightness").
- The chart's sky shows every gift as a literal star, drifting/twinkling in a parallax field.
- **Preset stars** (12 styles: gold, copper, rose, pearl, jade, amethyst, aurora, frost, comet, ruby, rainbow, dragon) are picked from a gallery.
- **Custom stars** are summoned via a guided prompt → animation → unique generated PNG that lands in the sky.
- Reaching the goal triggers a **celebration scene**; the chart then becomes a **constellation memory** (still sky, no further gifts).

## Screens / Views

8 scenes total. All available on both mobile (390×780) and desktop (1280×800) — same component tree, different breakpoint behavior.

### 1. Sign-in / First-time
- Full-bleed drifting sky background
- Centered: serif logo "Starcharts", sans-serif tagline, single text input ("group name or invite code"), "Continue" button
- "Use an invite code" link below
- All text on translucent surface chips so it reads on any palette

### 2. Dashboard
- Drifting sky background
- Header: small "your group" eyebrow → group name in serif → member dot list (colored dots, count) on the right
- **Chart grid**: `display: grid; gridTemplateColumns: repeat(auto-fill, minmax(320px, 1fr)); gap: 16px`
  - First tile is **"Create a new chart"** — dashed `2px` border in `--sc-fg-muted`, gold ✦ icon (28px), serif label, hover turns border + text gold
  - Each chart tile: `borderRadius: 18px`, `1px solid stroke`, `boxShadow: 0 8px 28px rgba(0,0,0,0.18)`, `height: 180px`
  - Tile content: live mini-sky behind, NO gradient overlay, three translucent capsules:
    - Top-left: chart name (serif 18, bg `rgba(8,10,20,0.55)` + 8px blur, 6/10px padding, 8px radius)
    - Top-right (only if complete): wreath icon in matching capsule
    - Bottom-left: reward (sans 11)
    - Bottom-right: "X of Y" pill (or italic "complete")
- Click any tile → opens its sky scene

### 3. Chart Sky (the hero)
- Full-bleed live sky with all gifted stars rendered as positioned points
- Top bar (translucent capsule): back arrow, chart name, gold progress "X / Y"
- Bottom-right floating action: gold "✦ Give a star" button
- Tap any star → bottom-sheet card showing: stylized star, "for [recipient]", reason text, "from [giver] · count"
- Presence dots: small colored dots at the top showing who's currently in the sky
- Stars twinkle, drift subtly (animation level controlled by tweak: still / drifty / lively)

### 4. Create Chart
- Single-page form (NOT multi-step): chart name, goal count (numeric, default 50), reward description
- Sky background, translucent form panel
- "Begin" button enabled when all three filled

### 5. Gift Flow (overlay/sheet)
- Step 1: pick honoree(s) — large tap targets, member color dot + name on left, serif name on right
- Step 2: write reason (multi-line text)
- Step 3: choose star — preset gallery (12 styles in a 4×3 grid) OR "Summon a custom star" CTA
- Step 4: confirm → animation → star arrives in sky

### 6. Custom Star Summoning
- Guided prompt input ("describe the moment in 3–5 words")
- Forming animation (~3s): swirling particles condense into the new star
- Result: one of 5 pre-baked custom-star SVGs (in production: an actual diffusion-model PNG)

### 7. Goal Reached
- Triggered on the gift that completes the chart
- Sky fills with a wave of light, wreath descends, serif "[Reward]" in oversized type, "Mark complete" CTA
- Marking complete archives the chart and freezes its sky as a constellation

### 8. Constellation Memory
- Same Chart Sky component but `animation="still"`, no add-gift button
- Title bar reads "Memory · [completion date]"

## Universal Chrome (every scene)

Top-right floating cluster:
- **Theme toggle**: segmented sun/moon, both options always visible, active one filled
- **Tweaks button**: opens floating panel (theme, sky palette, type pairing, density, animation level, persona)
- **Scene chip bar**: Sign in · Dashboard · Create (reviewer shortcuts; in production these are real nav)

## Interactions & Behavior

- **Sky parallax**: stars on 3 depth layers; nearest layer drifts ~15px over 30s
- **Gift arrival**: new star fades in over 1.2s with a brief halo bloom (scale 0.2 → 1.08 → 1.0)
- **Tile press**: `transform: scale(0.99)` on mousedown, restored on up/leave
- **Tap-to-inspect**: any star → bottom-sheet rises (`@keyframes sc-slide-up`) with details
- **Animations all respect** `prefers-reduced-motion` — fall back to "still" mode
- All translucent capsules use `backdrop-filter: blur(8–20px)` — confirm target platform support

## State Management

- `currentUser` (id)
- `group` (name + members[])
- `charts[]` (id, name, goal_count, reward, completed_at?)
- `gifts[]` (id, chart_id, honoree_ids[], giver_id, reason, count, style, star_image_url, created_at, x, y)
- `presence[]` (member ids currently in a given chart)
- Realtime: gifts + presence should sync via the platform's realtime layer (Firestore, Supabase Realtime, etc.)
- New gift insertion → triggers arrival animation on all clients

## Design Tokens

All tokens live in `tokens.jsx`. Each sky palette has full **dark + light** variants. Copy these values verbatim.

### Type pairings (3 options, default: cormorant)

```
serif: "Cormorant Garamond", "EB Garamond", Georgia, serif
sans:  "Inter", system-ui, sans-serif
```
Alternates: Fraunces + DM Sans · EB Garamond + Inter

### Sky palettes (4 options, default: midnight)

Each defines: `gradient[4]`, `nebulae[3]` (color + alpha), `dust`, `fg`, `fgMuted`, `fgFaint`, `surface`, `surfaceSolid`, `stroke`, `gold` — for both `dark` and `light` modes.

- **Midnight** — deep navy → indigo (dark) / dawn rose-gold (light)
- **Nebula** — purple/magenta cosmic (dark) / soft lavender (light)
- **Dawn** — navy with warm sunrise nebulae (dark) / peach/coral (light)
- **Aurora** — deep teal/green (dark) / mint/sky (light)

Exact hex values in `tokens.jsx` `SKY_PALETTES`.

### Spacing & radii
- Tile/sheet radius: 18px
- Pill/capsule radius: 999px
- Inline pill radius: 8px
- Standard gap: 16px (grid), 14px (column), 6–10px (inline)

### Shadows
- Tile: `0 8px 28px rgba(0,0,0,0.18)`
- Capsule border: `0.5px solid rgba(255,255,255,0.08)` (over dark sky)

### Typography scale
- Display serif: 28–48px (chart name on hero, reward on goal-reached)
- Section title: 18–22px serif
- Body: 14–16px sans
- Eyebrow / caption: 10–11px sans, `letter-spacing: 0.18–0.22em`, uppercase
- Min readable on 1920px context: 11px (eyebrows only)

## Notes for Implementation

- **Sky rendering**: in production this should be a Skia/Canvas/Metal layer, not DOM. Each star is a textured sprite with additive blend; the gradient + nebulae are radial-gradient layers.
- **Realtime is core**: the magic is seeing a star you didn't place arrive in the sky. Build the realtime layer first.
- **No notifications spam**: a daily digest of who gave what to whom is fine; per-gift push notifications are not.
- **Privacy**: charts are group-scoped. No public discovery, no follower model.
- **Accessibility**: every star needs an alt label ("Gold star — 'for the bedtime story voices' — from Aria"). Bottom-sheet must be keyboard-traversable. Honor reduced motion.
